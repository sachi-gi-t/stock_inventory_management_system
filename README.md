Stock Inventory Management System

-->  Description
A Python-based Stock Inventory Management System used to manage products, inventory records, and data visualization.

-->  Features
> Add and manage inventory
> Store inventory data using CSV
> Analytics and visualization
> Inventory tracking system

-->  Technologies Used
> Python
> Pandas
> Matplotlib
> CSV

-->  Files
> app.py - Main application
> inventory.py - Inventory operations
> analytics.py - Data analysis
> visualize.py - Charts and visualization
> data.csv - Inventory dataset
