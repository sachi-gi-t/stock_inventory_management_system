# Stock Inventory Management System

## 📌 Description
A Python-based Stock Inventory Management System designed to manage products, track inventory records, perform analytics, and visualize stock data efficiently.

---

## 🚀 Features
- Add and manage inventory
- Store inventory data using CSV
- Analytics and reporting
- Data visualization using charts
- Inventory tracking system

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

---

## 📂 Project Files
| File Name | Purpose |
|------------|---------|
| app.py | Main application |
| inventory.py | Inventory operations |
| analytics.py | Data analysis |
| visualize.py | Data visualization |
| main.py | Project execution |
| data.csv | Inventory dataset |

---

## ▶️ How to Run
```bash
python main.py
```
